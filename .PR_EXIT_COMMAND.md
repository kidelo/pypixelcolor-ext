# PR: Add `exit` command (leave current screen → saved-slot playlist)

## Summary

This PR adds a new `exit` command that returns the panel from the current screen to its saved-slot playlist. The command emits the exact bytes `[4, 0, 1, 1]` per protocol §6.1 (`sendExitCmd`).

Verified on real hardware (64×16 panel, device byte 131, LED type 3, MCU 14.02, BT 7.04).

## Protocol Reference

Per `IPIXEL_PROTOCOL_MASTER.md` §6.1 (Command catalog):

| Feature | Bytes | Notes |
|---|---|---|
| Exit / leave | `[4,0,1,1]` | `sendExitCmd` — return to saved-slot playlist |

Semantics: Exit/leave does **not** clear stored content or blank the screen. It returns the panel to its saved-slot playlist (cycling through saved slots).

## Byte Layout

```
data[0] = 4    # length (4 bytes total)
data[1] = 0    # length high byte (length < 256)
data[2] = 1    # command ID 0x0001 = exit/leave
data[3] = 1    # subcommand 1
```

Raw byte array, sent via `sendCompat` — **no header/CRC framing** (unlike image/text streams).

## Implementation

### `src/pypixelcolor/commands/exit.py`

```python
def exit_cmd() -> SendPlan:
    """Exit / leave the current screen (return to the saved-slot playlist).

    Protocol §6: `[4, 0, 1, 1]`.

    Returns:
        A SendPlan wrapping the exact exit command bytes.
    """
    cmd = bytes([4, 0, 1, 1])
    # Exit is a display/playlist operation; the device does not emit a notify ACK
    # for it (unlike stream commands), so we don't wait for one.
    return single_window_plan("exit", cmd, requires_ack=False)
```

**Key design decision: `requires_ack=False`**

The device does **not** emit a notify-ACK for display operations like exit (unlike stream commands). This matches the pattern used by sibling display commands:
- `set_fun_mode` — `requires_ack=False`
- `set_rhythm_mode` — `requires_ack=False`
- `set_rhythm_mode_2` — `requires_ack=False`
- `set_pixels` — `requires_ack=False`

Using `requires_ack=True` (the default) would cause a timeout (`cur12k_no_answer`) because the device never sends an ACK for exit.

### `src/pypixelcolor/commands/__init__.py`

Registered in `COMMANDS` dict:
```python
from . import (
    ...
    exit,
    ...
)
...
"exit": exit.exit_cmd,
```

## Notes

- The exit command is a display/playlist operation. It does **not** erase stored content (unlike `clear()`).
- The device does not emit a notify-ACK for exit, so `requires_ack=False` is used.
- Visual verification on the panel is required to confirm the playlist behavior (the panel cycles through saved slots after exit).
